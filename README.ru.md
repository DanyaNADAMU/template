# Базовый эталонный шаблон репозитория

Этот репозиторий представляет собой каноническую базовую структуру для всех проектов.

## Состав шаблона
- `.githooks/` — Версионируемые хуки для невидимого фонового запечатывания коммитов в OpenTimestamps.
- `.github/workflows/ots-cron.yml` — Ночной workflow для автоматического забора и проверки доказательств Bitcoin.
- `.allowed_signers` — Список доверенных открытых ключей для верификации подписей коммитов.
- `SECURITY.md` — Политика безопасности и привязка к домену nada.mu.
- `docs/` — Живая документация (Архитектура, ADR, Планы, Идеи, Руководства).
- `src/` — Исходный код приложения.
- `scripts/retrofit.sh` — Скрипт быстрого обновления старых репозиториев до этого стандарта.
